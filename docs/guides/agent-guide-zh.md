# 导入 Mosaic 指导

<p align="center"><a href="agent-guide.md">English</a> | <b>简体中文</b></p>

Mosaic 可以把完整的英文写作指导交给 Agent，形式可以是 Skill，也可以是普通 Markdown 指南。两者正文相同，都能独立使用。这个功能是可选项，不影响笔记渲染。

## 导入 Skill

所有目标开关默认**关闭**。打开「设置 → Mosaic → **Import skill**」，保持选中 **Current vault**（当前仓库），开启 Agent 使用的目录即可。一份就够用。

| 目标开关 | 当前仓库 | Global（仅桌面端） |
| --- | --- | --- |
| `.agents` | `.agents/skills/mosaic/SKILL.md` | 当前用户主目录下的同名路径 |
| `.claude` | `.claude/skills/mosaic/SKILL.md` | 当前用户主目录下的同名路径 |
| 自定义目录 | 所选上级目录 + `mosaic/SKILL.md` | 所选桌面目录 + `mosaic/SKILL.md` |

开启后立即导入，覆盖目标文件的全部内容，并在插件更新后继续覆盖。关闭后停止更新，文件保留。

高亮的 **Current vault** / **Global** 按钮只决定当前显示哪个范围的设置，不会改变各目标的开关。移动端只支持当前仓库。

### 选择目录

- 自定义 Skill 的上级目录默认为所选范围下的 `.agents/skills`。
- 桌面端点击路径框，直接打开系统文件夹选择框，初始位置是当前仓库。没有额外的选择按钮。需要显示隐藏目录时，使用系统弹窗提供的选项。
- 当前仓库范围只能选择仓库内部、配置目录以外的位置。移动端提供可搜索的仓库文件夹列表，也可以输入新的相对目录。
- 取消选择会保留原路径。选目录不会导入文件；在系统弹窗中新建文件夹，只会创建那个目录。
- 目标开启时，自定义路径框会锁定。先关闭，选择新目录，再开启。旧文件会留在原处。
- 自定义目录指向 `.agents/skills` 或 `.claude/skills` 时，两行对应同一个文件，开关状态也相同。关闭任意一行都会停止该文件的更新，其他目标不受影响。
- 仓库内显示相对路径。macOS/Linux 的全局主目录用 `~` 表示；Windows 显示完整系统路径。这只是显示方式，实际写入位置不变。

不同 Agent 发现、重新加载 Skill 的时机不同。如果 Agent 没有读到新内容，可以直接让它阅读该文件。

## 导入普通指南

如果想在 `AGENTS.md` 中引用一篇普通 Markdown 文档，可以使用 **Import guides to this vault (optional)**，代替 Skill。

目录默认为 `docs/guides`。开启开关后，会创建并持续更新：

```text
docs/guides/Mosaic-Usage-Guide.md
```

路径框使用与仓库内 Skill 相同的文件夹选择框。指南始终保存在当前仓库，即使 Skill 范围选了 Global 也一样。仓库根目录显示为 `/`。

在仓库的 `AGENTS.md` 中引用这篇指南，要求 Agent 在创建 Mosaic 内容前阅读它。Mosaic 只写入指南，不会替你修改 `AGENTS.md`。

## 自动更新方式

**开启就是交给 Mosaic 管理整篇文件；关闭就是保留文件、停止管理。**

- 从关闭变为开启：立即导入，覆盖整篇文件，包括你或 Agent 做过的修改。
- 插件版本变化后：已开启的目标会换成当前插件附带的指导内容。手动安装较旧插件版本时，也会跟随那个版本。
- Mosaic 不比较文件内容，不保留本地修改，不合并段落，也不创建备份。个人补充说明请放在另一篇文件中。
- 关闭后再开启：立即覆盖，即使插件版本没变。
- 从开启变为关闭：只保存关闭状态，不读取、写入、移动或删除目标文件。
- 每次插件加载、仓库就绪后检查一次。成功写入的版本会被记住，同一版本下重新打开 Obsidian 不会反复覆盖。
- 已开启的文件被删除或改名后，会在下次插件版本变化或重新开启开关时，按原路径重新创建。改名后的那份文件不受影响。
- 手动复制的文件，只有开启对应开关后才由 Mosaic 管理。插件不扫描仓库，也不寻找被移动的文件。

## 范围与文件权限

仓库内的写入使用 Obsidian 接口。桌面端 Global 写入使用 Node 文件系统权限，只处理所选 Skill 目标。目标本身是符号链接或目录时会报错。全局文件先完整写入临时文件，再替换目标，避免写到一半失败时破坏原内容。

Global 范围、自定义目录和开关记录只保存在当前仓库、当前设备的本地存储中，不放进同步的插件配置。关闭全局目标，只会停止**这个仓库**的更新；其他仓库如果仍开启相同目标，依然可以覆盖它。

这个功能没有网络请求、遥测、Agent 启动、客户端配置修改或文件扫描。某个目标失败，不影响其他目标更新，也不影响笔记渲染。复制按钮只写剪贴板，Mosaic 不读取剪贴板。

## 导入失败后怎么办

目标旁会显示错误；手动操作失败时，也会弹出提示。

- 保存开关状态失败：恢复原开关状态，目标文件不变。
- 已保存开启状态，但写文件失败：开关保持开启，下次加载插件时重试。
- 文件已写入，但保存成功版本失败：开关保持开启，之后会重新写入。
- 想立即重试：修复路径或权限问题，再关闭、开启一次。
- 想换目录：先关闭对应目标。关闭也会停止等待中的自动重试。
- 桌面端功能不可用时，全局导入会报错；仓库内导入和笔记渲染仍可使用。

## 使用指导

让 Agent 先阅读 Skill 或指南，再提供笔记所需的数据、字段含义和汇总规则。遇到信息不足时，让它提问，不要编造数值。最后在 Obsidian 阅读视图中检查结果。

完整语法、示例和排错说明请查看 [Mosaic 内容块指南](../README-zh.md#文档)。
